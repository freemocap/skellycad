# Historical release checkpoints

`mouse-hats-r02/` and `MouseHats_R02-release.zip` preserve the older R02 release.
The second identical expanded copy was omitted during migration, verified file
by file against the retained tree. The ZIP remains the distribution artifact.

R02 is historical. Active mouse selection is in
`designs/eye-tracker/mouse/active-model.json` at the repository root. New releases
should record a revision, exact checkpoint and source hashes, matched parts,
validation results and physical-test limitations.
