# Mouse-hats working rules

Before geometry edits or exports, read current/active-model.json and its README.
Use the hash-verified complete checkpoint and matched parts. INDEX.md classifies
historical studies. Older files named CURRENT and isolated variant selections
are history unless selected by the active manifest.

Preserve the current checkpoint for a new revision, record lineage and units,
and check affected interfaces before updating the manifest. Retain PCB catch,
tray height, cap engagement, matching cap, camera pose and ribbon loop unless
the user requests changes to them. Compare inherited contacts to their recorded
baseline; geometry validity alone does not establish physical fit.

Keep supplied sources unchanged. Use the pinned FreeCAD GUI runtime for document
mutations and show meaningful changes. Scope filesystem and Git work to this
playground. Historical scripts retain their paths for reproducibility. Export
current prints through current/export_print.py, which validates the manifest.
