# Named atlas references R03

This is a presentation of supplied atlas points, not a request for the user to
correct published coordinates. The eight colored spheres use the original
transferred coordinates, never the editable proposal positions. The editing
panel is closed. Remaining numeric landmarks stay available in the hidden groups.

The skull surface is reconstructed from the Maga atlas segmentation and reduced
for display; both the mesh and landmarks retain the preceding study's common
similarity transform [@maga2017MouseSkullAtlas; @magaMouseCTAtlasRepository].
Their relative relationship is preserved. This is not a vendor-supplied STL,
and alignment onto our older skull is our own exploratory registration.

An asterisk marks an interpreted name. Bregma, lambda, nasion and nasal tip
remain tentative ID-to-name mappings. Right/left outer and inner orbit reference
are descriptive regional labels, not verified author landmark definitions.
Exact source IDs and name status are properties of each colored sphere and are
recorded in labels.json. Coordinates are source-derived; English naming is a
separate, incompletely verified layer. No eye placement or camera geometry changes.

The useful user review is whether the labels are readable and the imported
reference is represented sensibly. Resolving source definitions and checking
coordinate transforms remain the agent's responsibility. No point editing is
required. The optional R02 editor remains available separately.

Open open.FCMacro through the existing desktop pipe following docs/development.md.
It opens a generated working copy and never overwrites the frozen checkpoint.
