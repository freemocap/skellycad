# Eye trackers

Choose an animal, then a hardware variant. Camera models are shared through the
[camera catalog](../cameras/README.md); mounting and targeting code lives in
[shared](shared/README.md).

| Animal | Current scope |
| --- | --- |
| [Mouse](mouse/README.md) | Monocular; selected complete R19 assembly, R23 anatomy/print derivative. |
| [Rat](rat/README.md) | Historical monocular selection, binocular R43 review, eye + world W06 review and corrected trial print package. |
| [Marmoset](marmoset/README.md) | Reference anatomy and skull print derivatives; no complete assembly selected. |
| [Human](human/README.md) | Placeholder; no assembly selected. |

A selected checkpoint, current candidate and print layout are separate records.
Geometry checks do not demonstrate physical fit. Read the variant README before
opening or exporting matched parts.
