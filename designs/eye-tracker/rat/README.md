# Rat eye tracker

Placeholder for species-specific design work. Add skull/anatomy assets under
`references/`, retaining original files and recording units, coordinate axes,
scale, provenance and anatomical landmarks alongside them.

No assembly or dimensions are selected yet. Camera count, placement and aiming
will be established from the supplied references using the shared hardware
components as they are extracted from the mouse design.

See [the eye-tracker collection](../README.md) for project boundaries.
