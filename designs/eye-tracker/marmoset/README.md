# Marmoset eye tracker

The [CT skull reference](references/skull/README.md) preserves the supplied
female, 100-month, 403 g marmoset scan and its source attribution
[@marmosetCtFemale100; @zimmermannRollin2025Apparatus]. The separate
[R02 skull print derivative](skull-print-r02/README.md) removes neck and loose
geometry, fills the braincase, backs the sockets, and reduces mesh size while
preserving the source surface. R01 is retained as a rejected revision.

No complete assembly is selected and no `active-model.json` exists. Units are
provisionally millimetres; source coordinates and scale 1.0 are retained.
Camera count, placement and aiming
will be established from the supplied references using the shared hardware
components as they are extracted from the mouse design.

See [the eye-tracker collection](../README.md) for project boundaries.
