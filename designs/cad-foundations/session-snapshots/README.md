# Preserved live state

Five documents were captured with FreeCAD saveCopy before relocating lesson
folders. index.json maps their original locations to these snapshots. The old
paths are provenance, not links to active files. Snapshots preserve possible
interactive edits and display state; numbered lesson checkpoints remain the
canonical historical artifacts. Reopened snapshots keep the live session usable
without pointing at moved files. Future experiments should use fresh replay
documents or Save As into a new design directory.
