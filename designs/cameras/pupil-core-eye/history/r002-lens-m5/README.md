# Fake lens insert

Adds a solid mock lens and retaining ring to the scaled 6.3 mm holder from lens-m5-r01. All dimensions are mm. Optical appearance is illustrative, not a measured lens prescription. A 2.24 radius barrel fills the opening, a 1.55 radius convex face rises to 2.8, and six shallow drive slots distinguish the retaining ring. The overall holder envelope is unchanged. CAD colors distinguish surfaces; the exported single-solid STL is all black PLA.

Run build.py with the pinned FreeCAD Python, then open open.FCMacro through the existing desktop listener. Exports are in generated/eye-tracker/shared/lens-m5-r02. Validation checks valid connected solid, closed mesh and outer envelope; print fit remains unverified. The prior holder and complete camera checkpoints remain intact.
