# Approved architecture checklist

- [x] **1. Define the three-board requirements and interfaces**, including recording modes, optical requirements, head-mounted mass, tether lengths, power delivery and enclosure/backpack configurations.
- [x] **2. Evaluate and recommend the component chain**, checking sensor availability, public documentation, serializer/deserializer compatibility and ESP32-P4 software support, with explicit unresolved blockers.
- [x] **3. Calculate the system budgets**, covering image throughput, buffering, timing, cable losses, supply margins, heat and mass for both tether lengths.
- [x] **4. Build initial KiCad architecture sheets and matched FreeCAD placement studies**, showing realistic component envelopes, one-sided camera-assembly options, supports and tether exits while preserving R11.
- [x] **5. Publish a reviewed architecture package**, with cited evidence, comparison against R11, expected versus unverified performance, and a clear recommendation for the subsequent detailed-design phase.
