# Capture enclosure

The frame and optical layout studies are concepts, not a qualified capture system.
[History](history/README.md) contains the revision-first sequence.

- [R01 frame](history/r001-starter-cube/README.md): 500 mm clear starter enclosure.
- [R04 capture geometry](history/r004-capture-study/README.md): five-view floor-overlap study.
- [R05 lens study](history/r005-lens-study/README.md): reported manual-varifocal lens range.
- [R06 withdrawn hardware recommendation](history/r006-usb-baseline/README.md): rectangular sensors failed the square-active-array requirement; retained for comparison only.

No hardware configuration is selected as accepted. Use the existing study source
through the isolated replay workflow; create a maintained `src/` when a current
configuration is selected rather than promoting the withdrawn R06 by its number.
